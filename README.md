# 또미 (DDOMI) — 사이트 배포 저장소

또 가고 싶은 진짜 맛집. 맛집 신뢰평가 플랫폼 랜딩/데모 사이트입니다.

- 조직 관리 문서(브랜드가이드·알고리즘 노트 등)는 별도 관리 저장소 `Hwang-InHoo/gicho-hoesa`의 `subsidiaries/ddomi/`에 있습니다.
- 페이지: `index.html`(홈) · `about.html`(소개) · `demo.html`(고통지수 데모) · `map.html`(카카오맵 맛집 지도)
- 정적 사이트(빌드 없음). Vercel Framework Preset = Other, Root Directory = 루트.
