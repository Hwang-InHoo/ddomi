# 또미 소유 음식점 데이터

`restaurants.json` — 또미가 **소유**하는 음식점 목록입니다. 행안부 **LOCALDATA 인허가 데이터**에서
`tools/localdata.py`(gicho-hoesa 저장소)로 뽑아 좌표를 WGS84로 변환해 생성합니다.
카카오/네이버처럼 빌린 데이터가 아니라 재배포 가능한 공공데이터이므로 사이트가 직접 소유·배포합니다.

## 스키마 (배열의 각 항목)

| 필드 | 설명 |
| --- | --- |
| `id` | 관리번호(LOCALDATA `MGTNO`) — 고유 식별자 |
| `name` | 상호명 |
| `category` | 업종/업태 (예: 한식, 카페) |
| `roadAddr` | 도로명주소 |
| `addr` | 지번주소 |
| `lat` | 위도 (WGS84, 숫자) |
| `lng` | 경도 (WGS84, 숫자) |
| `status` | 영업상태 (영업중만 담음) |

점수(또미 신뢰점수)는 이 파일에 넣지 않습니다 — 실제 미식가 평가가 쌓이기 전까지 모든 가게는
지도에서 "평가 준비중"으로 표시됩니다(가짜 점수 금지 원칙, CLAUDE.md 또미 알고리즘 노트 참고).

현재는 빈 배열입니다. VWorld·LOCALDATA 인증키가 `.env`에 준비되면 `tools/localdata.py`로 부산 서면
데이터를 채웁니다.
